Deine Daten sichern

Die Einträge werden lokal in dieser App auf deinem Smartphone gespeichert. Sie werden nicht an einen Server gesendet. Wenn du Browserdaten löschst oder den Browser wechselst, können sie verloren gehen. Deshalb regelmäßig eine Sicherung exportieren.

JSON ist für die Wiederherstellung gedacht; CSV lässt sich in Excel öffnen.

Beim Import werden vorhandene gespeicherte Einheiten durch die importierte Sicherung ersetzt. Bitte vorher exportieren.
